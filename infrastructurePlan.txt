SELECTED INFRASTRUCTURE STACK

Frontend Architecture:

Framework: React Native

Target Platforms: Cross-platform mobile (iOS & Android)

Backend & Hosting:

Application Framework: Spring Boot (Java RESTful API backend handling
business logic, user accounts, groups, capsules, and push scheduling).

Cloud Hosting: Virtual Private Server (VPS).

Deployment Architecture: Direct host deployment managed via systemd
services and Nginx reverse proxy with SSL/TLS termination.
(Note: Docker is NOT being used for this deployment pipeline).

Database & Storage:

Relational Database: MySQL hosted on the VPS / managed server instance.
Stores structured application data (users, group memberships,
capsule release dates, memory metadata, locations).

Media & Blob Storage: AWS S3 / S3-compatible cloud object storage
dedicated to hosting uploaded high-res photos, user media, and
compiled recap videos.

Third-Party Services & Integrations:

Push Notifications: Firebase Cloud Messaging (FCM) / APNs for capsule
opening alerts and group updates.

Maps & Geolocation: Google Maps API / Mapbox SDK for the interactive
Memory Map feature and location tagging.
